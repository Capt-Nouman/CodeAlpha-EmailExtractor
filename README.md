# ✨ Features

✔ Extracts email addresses from any `.txt` file

✔ Uses Regular Expressions (Regex) for accurate matching

✔ Automatically removes duplicate email addresses

✔ Generates a clean output file

✔ Beginner-friendly and lightweight

✔ Fast and efficient processing

✔ No external libraries required

# ⚙️ How It Works

The script follows these simple steps:

1. Reads the input text file.
2. Searches for email addresses using Regex.
3. Removes duplicate emails automatically.
4. Counts total unique emails found.
5. Saves results into an output text file.

# 🚀 Getting Started

## Prerequisites

Make sure Python is installed:

```bash
python --version
```

or

```bash
python3 --version
```

---

## Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/email-extractor.git
```

Move into project directory:

```bash
cd email-extractor
```

---

# ▶ Running the Project

Run the script using:

```bash
python Email-Eextractor.py
```

or

```bash
python3 Email-Extractor.py
```
